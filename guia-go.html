1. Introdução ao Go

Go (ou Golang) é uma linguagem de programação criada pelo Google em 2009. Foi projetada para ser simples, eficiente e com excelente suporte a concorrência.

Por que aprender Go?
  • Sintaxe limpa e fácil de aprender
  • Compilação extremamente rápida
  • Concorrência nativa com goroutines
  • Tipagem estática forte
  • Ótima para APIs, CLIs e sistemas distribuídos

Características Principais

Simplicidade

Go tem poucas palavras-chave e uma especificação pequena. É possível aprender a linguagem inteira em poucas horas.

Concorrência

Goroutines e channels tornam a programação concorrente simples e segura.

Performance

Compilada para código nativo, com garbage collector eficiente.

Tooling

Ferramentas embutidas: formatação (go fmt), testes, documentação, gerenciamento de dependências.

2. Configuração do Ambiente

Instalação

Baixe e instale Go pelo site oficial: go.dev/dl

Verificar instalação

go version
// Saída esperada: go version go1.21.x linux/amd64

Estrutura de um Projeto Go

meu-projeto/
├── go.mod          # Módulo e dependências
├── go.sum          # Checksums das dependências
├── main.go         # Ponto de entrada
├── cmd/            # Múltiplos binários
├── internal/       # Código privado do módulo
├── pkg/            # Código reutilizável
└── api/            # Handlers, rotas, etc.

Criar um novo módulo

mkdir meu-projeto
cd meu-projeto
go mod init github.com/usuario/meu-projeto
go.mod define o módulo, versão do Go e dependências. É o equivalente ao package.json do Node.js.

3.6 Funções

// Função simples
func somar(a, b int) int {
    return a + b
}

// Múltiplos retornos
func dividir(a, b float64) (float64, error) {
    if b == 0 {
        return 0, fmt.Errorf("divisão por zero")
    }
    return a / b, nil
}

// Função variádica
func somaTudo(numeros ...int) int {
    total := 0
    for _, n := range numeros {
        total += n
    }
    return total
}

// Função anônima e closure
func main() {
    duplicar := func(x int) int { return x * 2 }
    fmt.Println(duplicar(5)) // 10

    // Closure com estado
    proximo := contador()
    fmt.Println(proximo(), proximo(), proximo()) // 1 2 3
}

func contador() func() int {
    i := 0
    return func() int {
        i++
        return i
    }
}

4. Conceitos Intermediários

4.1 Ponteiros

func main() {
    x := 10
    p := &x  // p é um ponteiro para x

    fmt.Println(p)   // endereço de memória
    fmt.Println(*p)  // valor apontado (10)

    *p = 20  // altera o valor de x
    fmt.Println(x)   // 20
}

// Função com ponteiro (passagem por referência)
func dobrar(n *int) {
    *n *= 2
}

4.2 Interfaces

type Animal interface {
    Som() string
}

type Cachorro struct{}
type Gato struct{}

func (Cachorro) Som() string { return "Au au!" }
func (Gato) Som() string    { return "Miau!" }

func emitirSom(a Animal) {
    fmt.Println(a.Som())
}

// Interface vazia (aceita qualquer tipo)
func imprimir(v interface{}) {
    fmt.Println(v)
}

4.3 Goroutines e Concorrência

func main() {
    // Goroutine (execução concorrente)
    go func() {
        fmt.Println("Executando em paralelo")
    }()

    // WaitGroup para sincronização
    var wg sync.WaitGroup
    wg.Add(1)

    go func() {
        defer wg.Done()
        fmt.Println("Goroutine completa")
    }()

    wg.Wait() // espera todas terminarem
}

4.4 Channels

func main() {
    // Channel unbuffered
    ch := make(chan int)

    go func() {
        ch <- 42  // envia valor
    }()

    valor := <-ch  // recebe valor
    fmt.Println(valor)

    // Channel buffered
    chBuf := make(chan string, 2)
    chBuf <- "a"
    chBuf <- "b"
    fmt.Println(<-chBuf, <-chBuf)

    // Select (multiplexação de channels)
    ch1 := make(chan string)
    ch2 := make(chan string)

    go func() { ch1 <- "um" }()
    go func() { ch2 <- "dois" }()

    for i := 0; i < 2; i++ {
        select {
        case msg1 := <-ch1:
            fmt.Println("ch1:", msg1)
        case msg2 := <-ch2:
            fmt.Println("ch2:", msg2)
        }
    }
}

4.6 Defer, Panic e Recover

// Defer: executa ao final da função
func main() {
    defer fmt.Println("1 - executado por último")
    defer fmt.Println("2 - penúltimo")
    fmt.Println("3 - primeiro")
}

// Panic e Recover
func dividir(a, b int) (resultado int) {
    defer func() {
        if r := recover(); r != nil {
            fmt.Println("Recuperado de panic:", r)
            resultado = 0
        }
    }()
    return a / b  // panic se b == 0
}

4.7 Generics (Go 1.18+)

// Função genérica
func Max[T constraints.Ordered](a, b T) T {
    if a > b {
        return a
    }
    return b
}

// Tipo genérico
type Lista[T any] struct {
    itens []T
}

func (l *Lista[T]) Adicionar(item T) {
    l.itens = append(l.itens, item)
}

func (l *Lista[T]) Obter(indice int) T {
    return l.itens[indice]
}

4.9 Testes

// arquivo: main_test.go
package main

import "testing"

func TestSomar(t *testing.T) {
    resultado := somar(2, 3)
    esperado := 5
    if resultado != esperado {
        t.Errorf("somar(2,3) = %d; esperado %d", resultado, esperado)
    }
}

// Teste de tabela
func TestSomarTabela(t *testing.T) {
    testes := []struct {
        a, b, esperado int
    }{
        {1, 2, 3},
        {0, 0, 0},
        {-1, 1, 0},
    }
    for _, tt := range testes {
        t.Run(fmt.Sprintf("%d+%d", tt.a, tt.b), func(t *testing.T) {
            if got := somar(tt.a, tt.b); got != tt.esperado {
                t.Errorf("got %d, want %d", got, tt.esperado)
            }
        })
    }
}

4.10 Context (Timeout e Cancelamento)

func buscarDados(ctx context.Context) (string, error) {
    select {
    case <-ctx.Done():
        return "", ctx.Err()
    case <-time.After(2 * time.Second):
        return "dados obtidos", nil
    }
}

func main() {
    ctx, cancel := context.WithTimeout(
        context.Background(),
        1*time.Second,
    )
    defer cancel()

    resultado, err := buscarDados(ctx)
    if err != nil {
        fmt.Println("Timeout!")
    }
}

5. Projetos Práticos

Projeto 1: CLI de Lista de Tarefas (Todo List)

Iniciante Intermediário

Descrição: Um gerenciador de tarefas via terminal que permite adicionar, listar, marcar como concluída e remover tarefas. Os dados devem ser persistidos em um arquivo JSON.

Funcionalidades

  • Adicionar nova tarefa com descrição e prioridade
  • Listar todas as tarefas (pendentes e concluídas)
  • Marcar tarefa como concluída
  • Remover tarefa
  • Filtrar por status ou prioridade
  • Persistência em arquivo JSON

Conceitos Praticados

  • Structs e métodos
  • Manipulação de JSON
  • Leitura/escrita de arquivos
  • Flags e argumentos de CLI (pacote flag)
  • Tratamento de erros
  • Slices e maps

Exemplo de Uso

./todo add "Estudar Go" --prioridade alta
./todo list
./todo complete 1
./todo remove 2

Projeto 2: Servidor de Encurtador de URLs

Intermediário

Descrição: Uma API REST que recebe URLs longas e gera códigos curtos únicos. Ao acessar o código curto, o usuário é redirecionado para a URL original. Inclui contador de acessos.

Funcionalidades

  • POST /encurtar — recebe URL, retorna código curto
  • GET /{codigo} — redireciona para URL original
  • GET /stats/{codigo} — retorna estatísticas de acesso
  • Validação de URL
  • Geração de códigos únicos (base62)
  • Persistência em memória (map) ou arquivo

Conceitos Praticados

  • HTTP server (pacote net/http)
  • JSON encoding/decoding
  • Structs e interfaces
  • Tratamento de erros HTTP
  • Testes de handlers
  • Concorrência (mutex para acesso ao map)

Exemplo de Uso

curl -X POST -d '{"url":"https://exemplo.com"}' localhost:8080/encurtar
# Resposta: {"codigo":"abc123","url_curta":"/abc123"}

curl -L localhost:8080/abc123
# Redireciona para https://exemplo.com

Projeto 3: API REST de Blog com Autenticação

Intermediário Avançado

Descrição: Uma API REST completa para um blog com autenticação JWT, CRUD de posts e comentários, middleware de autorização, e banco de dados SQLite.

Funcionalidades

  • Registro e login de usuários (bcrypt para senhas)
  • Autenticação via JWT (access token)
  • CRUD completo de posts (título, conteúdo, autor, tags)
  • CRUD de comentários em posts
  • Busca e filtros (por autor, tag, data)
  • Paginação de resultados
  • Middleware de autenticação e logging
  • Validação de dados
  • Testes unitários e de integração

Stack Sugerida

  • net/http ou gin-gonic/gin (router)
  • gorm.io/gorm + sqlite3 (ORM)
  • golang-jwt/jwt (autenticação)
  • golang.org/x/crypto/bcrypt (hash de senhas)

Conceitos Praticados

  • Arquitetura em camadas (handler, service, repository)
  • Interfaces para desacoplamento
  • Middlewares
  • JWT e segurança
  • Banco de dados e migrations
  • Testes com mocks
  • Tratamento de erros centralizado
  • Context para timeout e valores
